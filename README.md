# User Balance Test Project

## Описание 

### Цель проекта
Реализация баланса пользователя устойчивого к конкурентному доступу. Поставленная цель достигнута благодаря транзакциям и блокировке пользователя при изменении баланса

Возможная доработка - добавление проверки на идемпотентность запроса

### Эндпоинты:
- debit - начисление денег на счет пользователя
- credit - списание средств

Request Body для обоих эндпоинтов:
```json
{
  "amount": "100.00"
}
```
где amount - обязательно число с двумя знаками после запятой в виде строки

## Запуск проекта

`make up` - поднятие базы данных в контейнере

`make start_dev` - запуск самого приложения
